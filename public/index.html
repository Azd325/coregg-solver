    How it works

    What is the Mastermind minigame?

    In Cor3.gg, the Cleaner Bot (Space Roomba) stage and decrypt jobs open a four-field puzzle. Players report that the Fetcher bot uses the same minigame. You pick Version, Method, Channel and Cipher, for example v1.0 GET LTE AES. The game tells you how many fields are wrong. It is a Mastermind variant, close to Bulls and Cows. Cor3.gg is the web game that goes with Fragmentary Order.

    How does the solver pick a move?

    Each field has three values, so there are 81 combinations. The solver keeps the combinations that still fit and counts how many of them each move can still hit within the attempts left, and suggests the move with the highest count. Enter the mismatch count (0 to 4) the game shows after each try.

    How many attempts do I get?

    Players report 4 or 6 attempts, depending on the mode. The solver starts at 6. Use the attempts left control at the top to match what the game shows. Players also report a 20-minute wait after a failure.

    What happens after a failed round?

    The game picks a new target. Press New round to clear this round and start again with all 81 combinations.
