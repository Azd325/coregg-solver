    System Log Integrity

    Paste the log lines from the System Log Integrity puzzle, one per line. Each faulty line shows the error button to press. The two lines with the most faults are the pair to pick.

      How the checker judges a line

      A valid line reads [HH:MM:SS] TYPE /sector=N /status=S. Hour is 00 to 23, minute and second 00 to 59, and a space follows the closing bracket. TYPE is AUTH, TEMP-SYNC, SCAN, ROUTE-CHECK, RADIO-TEST, PING or SYNC in upper case. N is a whole number from 1 to 256. S is OK, WARN or ERROR. A line has at most one fault per rule, and the pick is the two lines with the most faults. When two lines tie for second place, the earlier line is marked.

      Signal Hack decoder

      Paste the pulses from the Signal Hack puzzle as S for short and L for long, for example SSSLSLLS. The page shows each reading that fits.

        How the decoder reads pulses

        Morse reads groups of 5 pulses and binary reads groups of 4. A reading counts only when the pulse count divides by the group size and every group is a digit from 0 to 9. When 40 pulses fit both, the game uses binary, so only binary shows. Any other pulse count that fits both shows both readings, and the page cannot decide between them.

        How it works

        What is the Mastermind minigame?

        In Cor3.gg, the Cleaner Bot (Space Roomba) stage and decrypt jobs open a four-field puzzle. Players report that the Fetcher bot uses the same minigame. You pick Version, Method, Channel and Cipher, for example v1.0 GET LTE AES. The game tells you how many fields are wrong. It is a Mastermind variant, close to Bulls and Cows. Cor3.gg is the web game that goes with Fragmentary Order.

        How does the solver pick a move?

        Each field has three values, so there are 81 combinations. The solver keeps the combinations that still fit and counts how many of them each move can still hit within the attempts left, and suggests the move with the highest count. Enter the mismatch count (0 to 4) the game shows after each try.

        How many attempts do I get?

        Players report 4 or 6 attempts, depending on the mode. The solver starts at 6. Use the attempts left control at the top to match what the game shows. Players also report a 20-minute wait after a failure.

        What happens after a failed round?

        The game picks a new target. Press New round to clear this round and start again with all 81 combinations.
